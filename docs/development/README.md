# Development archive

The files under `archive/` preserve the original fork design discussions,
implementation chronology, and S3DF/NERSC qualification records. They retain
historical names, paths and commands intentionally; some relative links refer
to the original layout. They are excluded from the published user documentation.

Start with the repository README for current usage. In particular, older
proposals describe features that were narrowed, superseded, or never implemented.
Qualification records prove the specific workloads recorded, not every possible
application or distributed topology.
